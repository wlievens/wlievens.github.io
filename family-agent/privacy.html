Family Agent privacy policy

Family Agent is a private assistant run by Wouter Lievens for his own household. Only family members can sign in to it.

What it accesses

  • Google Calendar: to read and add events the family asks for.
  • Gmail (read-only, the assistant's own mailbox): to read mail that a family member forwards to it. It never sends mail.
  • Google Contacts (read-only): names and birthdays only, for birthday reminders.

How the data is handled

  • Data is processed on a private server operated by the family. Only names and birthdays are kept from contacts; forwarded mails and their attachments are deleted once handled.
  • To act on a request, the relevant text may be sent to an AI model provider (Anthropic), and voice messages to a speech-to-text service, for processing. Nothing is sold or shared for advertising.
  • Google user data is used only to provide these features, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.
